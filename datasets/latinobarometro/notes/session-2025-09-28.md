## What Was Done

1. **Downloaded two waves** from latinobarometro.org in SPSS (.sav) format:
   - 2015 (English): `Latinobarometro_2015_Eng.sav`
   - 2023 (English): `Latinobarometro_2023_Eng_Spss_v1_0.sav`
   - PDF questionnaires for both years are also in the folder.

2. **Built an automated codebook/exploration script**:
   - File: `code/00_explore_codebook.R`
   - Loads both waves with `haven::read_sav()`
   - Extracts variable labels, value labels, types, and missingness
   - Heuristically tags variables by theme (democracy, economy, trust, corruption, vote, media, social, identity)
   - Compares variable overlap across waves
   - Exports everything to a multi-sheet Excel workbook

3. **Generated output files**:
   - `output/latinobarometro_codebook.xlsx` — searchable codebook with 5 sheets
   - `output/latinobarometro_exploration.RData` — loaded data frames and codebook objects for downstream work

| 2023 | 19,205 | 274 | 17 (Nicaragua absent) |

### Cross-wave comparability WARNING
- Only **51 variables** share the exact same name in both waves.
- **287 variables** are unique to 2015; **223** are unique to 2023.
- **47 variables** kept the same name but changed their label/description.
- This implies a **major questionnaire redesign** occurred between 2015 and 2023.
- For time-series/cross-wave research, intermediate waves (2017, 2018, 2020, 2021, 2022) should be downloaded to trace whether changes were gradual or abrupt.
